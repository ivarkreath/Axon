Реальный Electron: `npm run test:desktop` — 28 PASS; `node tests/review-desktop.mjs` — 7 PASS. Пройдены `interactions.mjs`, `gestures-desktop.mjs`, `workspace-desktop.mjs`, `close.mjs`, `recovery.mjs`, `verify-exports.mjs`, `evolution-desktop.mjs`, `corrections-desktop.mjs`, `controls-desktop.mjs`, `controls-exports.mjs`, `panels-desktop.mjs`, `background-desktop.mjs`, `quick-color-desktop.mjs` (все в `tests/`, каждый запущен через `node`). Проверены Save во время drag/русского ввода, независимые dirty/history двух вкладок, Undo/Redo, сохранение A при изменении B, ошибки записи и settings после записи, отмена диалога с сохранением recovery, версии файлов, поддеревья mind map, snapping и группы. SVG/PNG/PDF экспорт проверен через UI, PDF.js и внешний Edge; сцена и PDF визуально просмотрены. Тесты используют отдельные профили.

В первом итоговом `corrections-desktop.mjs` привязка конца новой стрелки неожиданно дала `free` вместо `bound` (строка 300). Два последовательных полных повтора прошли на 25/50/100/200%; причина первого сбоя не установлена. По исходникам поиск привязки не изменён и не использует новые кэши. Проверка сохранена без ослабления; добавлены масштаб и координаты в сообщение ошибки. Единичный сбой не объявлен исправленным дефектом.

`tests/review-performance.mjs` создаёт детерминированные сцены на 1000/5000/9000 самостоятельных объектов (25% connectors, включены в число), использует реальный PNG 1024×1024, 2 142 369 encoded bytes / 2 856 492 base64 chars. Node-замеры: два синхронных / один асинхронный прогрев, семь отсчётов; save/open/recovery включают файловую систему, не UI/IPC. P95 при семи отсчётах близок к максимуму и не является устойчивой оценкой хвоста. Память оценивается снимками процесса, абсолютные числа зависят от GC/нагрузки.

`tests/review-performance-desktop.mjs` запускает production dist в Electron с отдельным userData, фиксирует видимость/фокус, rAF интервалы, DOM mutations и CDP script/layout/task duration. На действие приходится один непрерывный прогон (drag — 30 шагов); интервалы включают cadence Playwright, это не независимые повторы и не полная задержка input-to-photon. DOM mutations не названы количеством вызовов React render. Число вызовов построения маршрута и glyph paths проверяется также детерминированными тестами. Исходный 5000-object прогон с аномальными интервалами ~1005 ms исключён из сравнения; повтор с явным фокусом сохранён отдельно. Исходники функциональных тестов/сцены не включаются в release.
