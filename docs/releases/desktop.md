## Windows

Скачайте `Axon-<version>-Setup-x64.exe`, запустите установщик и выберите папку установки. После установки откройте Axon через меню «Пуск» или ярлык. Node.js и отдельная установка зависимостей не нужны.

Установщик предназначен для 64-битной Windows (x64). Он пока без сертификата Authenticode; Windows может показать предупреждение о неизвестном издателе.

Перед публикацией CI выполняет lint, unit-тесты и сборку, проверяет содержимое приложения, затем действительно устанавливает EXE на отдельном Windows-runner и запускает установленный Axon с проверкой PDF-экспорта.

## macOS

- `Axon-<version>-mac-arm64.dmg` — Apple Silicon (M1 и новее).
- `Axon-<version>-mac-x64.dmg` — Intel.
- ZIP содержит тот же `Axon.app` без образа диска.

Откройте DMG и перенесите Axon в «Программы». Приложение подписано ad-hoc, без Apple Developer ID и notarization. Если macOS блокирует первый запуск, после попытки открытия зайдите в «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» для Axon. [Инструкция Apple](https://support.apple.com/en-us/102445).

Обе Mac-архитектуры проходят проверку DMG/ZIP, подписи, запуска и сохранения документа. Выпуск отмечен предварительным из-за отсутствия сертификатов подписи.

`SHA256SUMS.txt` содержит контрольные суммы всех установщиков и архивов. В PowerShell хеш файла можно проверить командой `Get-FileHash .\Axon-<version>-Setup-x64.exe -Algorithm SHA256`.
