## Установка на Mac

- `Axon-<version>-mac-arm64.dmg` — Apple Silicon (M1 и новее).
- `Axon-<version>-mac-x64.dmg` — Intel.
- ZIP — тот же `Axon.app` без образа диска.
- `SHA256SUMS.txt` — контрольные суммы: `shasum -a 256 -c SHA256SUMS.txt` в папке со всеми четырьмя файлами.

Откройте DMG и перенесите Axon в «Программы». Для ZIP распакуйте архив и перенесите `Axon.app` туда же. Node.js для готового приложения не нужен.

Приложение подписано ad-hoc, без Apple Developer ID и notarization, поэтому релиз помечен предварительным. Если macOS блокирует первый запуск, после попытки открытия зайдите в «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» для Axon. [Инструкция Apple](https://support.apple.com/en-us/102445).

Обе архитектуры собираются и запускаются на отдельных Mac в GitHub Actions. Перед публикацией проверяются типы, lint, unit-тесты, целостность DMG, содержимое пакетов, подпись, запуск приложения, ввод кириллицы и сохранение документа через Cmd+S. Автоматические проверки не заменяют проверку всех сценариев на пользовательском Mac.
