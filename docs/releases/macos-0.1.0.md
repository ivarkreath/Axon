Сборки Axon 0.1.0 для macOS:

- `Axon-0.1.0-mac-arm64.dmg` / `.zip` — Apple Silicon (серии M).
- `Axon-0.1.0-mac-x64.dmg` / `.zip` — Intel.
- `SHA256SUMS.txt` — контрольные суммы файлов.

Откройте DMG и перенесите Axon в «Программы». Альтернатива: распакуйте ZIP и перенесите `Axon.app` в «Программы». Node.js и установка зависимостей для запуска готового приложения не нужны.

Сборка выполняется на отдельных macOS-runner для каждой архитектуры. Перед публикацией проходят typecheck, lint, тесты модели, проверка DMG, распаковка ZIP, проверка локальной подписи и запуск именно распакованного приложения с созданием фигуры, вводом кириллицы, Cmd+A, Cmd+S и сохранением `.axon`.

Приложение имеет локальную подпись ad-hoc. Сертификат Apple Developer ID и notarization отсутствуют; это предварительный релиз. Автоматические проверки не заменяют проверку физического трекпада, нескольких мониторов и всех сценариев редактора на пользовательском Mac.
