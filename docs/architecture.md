# Архитектура Axon

Axon — Electron + React + TypeScript. Сервер, база данных и удалённые ресурсы отсутствуют. Vite используется только для разработки и сборки renderer; это не отдельная веб-версия продукта.

## Выбор основы

Нативный SVG Chromium выполняет растеризацию, hit testing и трансформации. React управляет SVG-узлами; D3 Shape формирует пути линий. Отдельный графический движок не пишется. Такой подход даёт контроль над интерфейсом, офлайн-работой и векторным экспортом без чужой доски/iframe.

## Поток данных

Жест сохраняет исходный immutable-документ, публикует предварительные состояния и завершает одну запись истории. Изменяется только нужный объект; неизменённые объекты и base64-строки разделяются по ссылкам. React подписан через `useSyncExternalStore`; камера и выделение не входят в переносимый документ, но сохраняются в рабочей сессии вкладки.

Связи хранят ID и сторону, не закэшированные экранные точки. Экран и экспорт вычисляют концы из текущих размеров узлов. Подпись принадлежит связи и лежит на половине длины маршрута.

Экранный текст использует SVG `text` и локальные Noto; переносы и метрики рассчитываются общим модулем. В экспорте те же строки превращаются в векторные контуры, поэтому у получателя не должны быть установлены эти шрифты. Неизменённые объекты мемоизированы; масштаб камеры не заставляет заново строить контуры каждой буквы.

Editor сохраняет только последний результат проверки dirty каждой открытой вкладки, пока ссылки на immutable-документ и сохранённое содержимое не изменились. Перемещение камеры и выделение не запускают повторную сериализацию. PDF-библиотека загружается из локального chunk при первом PDF-экспорте; повторные изображения внутри одного PDF используют общий встроенный ресурс.

## Безопасность desktop

`contextIsolation: true`, `sandbox: true`, `nodeIntegration: false`, `webSecurity: true`. Preload раскрывает конечный набор операций. Main проверяет webContents, главный frame, точный URL, enum/структуру/размер аргументов. В renderer нет shell, Node, произвольного чтения или записи путей. New/Open/Save используют стандартные диалоги; recent и folder принимают только индекс списка, хранящегося в main. session ID проверяется по реестру вкладок, view проходит Zod-валидацию.

Навигация и новые окна заблокированы, запросы разрешений отклоняются, удалённые запросы блокируются. CSP запрещает внешние скрипты, frames, objects; изображения — только локальные raster data. Импортируемые строки никогда не интерпретируются как HTML. Импорт изображений декодируется и нормализуется в PNG в main. Из файлов проекта принимаются только PNG/JPEG base64, без URL/путей.

## Persistence

Перед ручной записью проверяется общий размер UTF-8: больше 80 МБ не записывается, чтобы не создать файл, который не пройдёт ограничение чтения. Ошибки платформы и IPC преобразуются в понятные сообщения через `src/shared/errors.ts`.

FileWorkspace в main владеет реестром вкладок, путями, последними сохранёнными снимками и отпечатками файлов. Editor в renderer хранит отдельные состояние/History каждой вкладки. Завершение сохранения обновляет метаданные исходной сессии; новый текст не заменяется результатом старого snapshot. Renderer передаёт изменения с debounce 120 мс; recovery пишется ещё через 800 мс. Закрытие отдельно запрашивает актуальные документы всех вкладок у renderer, чтобы изменение перед закрытием не потерялось внутри debounce. Ручное сохранение сериализует, пишет соседний временный файл, вызывает fsync и заменяет целевой файл rename. При ошибке существующий файл остаётся.

Recovery последовательно пишет отдельный JSON с activeId и tabs, без истории между запусками. `RecoveryWriter` объединяет autosave, финальную запись и удаление recovery в одну очередь. Сериализация выполняется при начале записи; устаревшие ожидающие autosave отменяются. Обновления во время финальной операции откладываются до её завершения с прежним debounce 800 мс. Старая однодокументная рабочая копия читается как одна вкладка. Закрытие приложения сначала собирает решения для всех вкладок: отмена не применяет уже выбранные отбрасывания. Перед явным отбрасыванием отменяется таймер, ожидается текущая запись и атомарно записывается сессия без отброшенных вкладок. Только после успешной записи вкладка удаляется из реестра; ошибка recovery оставляет её доступной. Ошибка копии показана отдельно от ручного сохранения. Гарантируется только последняя завершённая запись, не последние события до сбоя питания.

Новые IPC: `axon:activate`, `axon:close-tab`, `axon:folder`. Файловые команды и update передают session ID; рабочая папка хранится в settings, не в документе. Open проверяет содержимое до добавления вкладки и идентичность реального пути/файла. Для удалённого файла путь нормализуется через ближайшую существующую родительскую папку: ссылки на каталоги, включая `/var` → `/private/var` на macOS, сохраняют идентичность пути при проверке конфликта. Save сравнивает SHA-256 с последним прочитанным/записанным содержимым; конфликт требует Save As/отмены. Недоступный исходный файл не уничтожает recovery-копию.

## Геометрия расширенного редактора

`model/transform.ts` масштабирует immutable-снимок множества объектов; `quickCreate.ts` ищет место и создаёт фигуру со связью; `mindmap.ts` создаёт двустороннее текстовое дерево v3 и раскладывает затронутую сторону после структуры/размера текста. `operations.expandSelection` учитывает группы; операции включают потомков без повторного преобразования, видимое выделение темы — без потомков. `shared/documentName.ts` задаёт имя из метаданных сеанса. `ui/PropertyPopover.tsx` сохраняет текстовый фокус; dock и однострочные свойства находятся в экранном overlay. Структурная ветвь хранит child ID, её привязки валидируются вместе с деревом. `primitives` принимает необязательный viewport zoom только от ObjectView: экспорт не получает экранные компенсации.

## Реальные ограничения

Независимые startMarker/endMarker расширяют существующий Connector; resolver сохраняет legacy arrows без переписывания при чтении. `model/markers.ts` и `geometry.connectionHeads` разделяются bounds и renderer/export. UI использует общие ColorPicker/VisualPicker/PropertyPopover/TooltipLayer; меню «Тема» меняет document.background через Editor.change, preferences.theme остаётся отдельным. Windows publication вынесена в `scripts/publish-windows.mjs` с проверкой staging, заменой полного каталога, откатом и проверкой канонического запуска; продуктового updater нет.

История снимков ограничена 100 действиями. SVG DOM не виртуализируется: 400 объектов проверяются отдельно, 10 000 — предел структуры файла, а не обещание интерактивной производительности. Маршруты не обходят препятствия. Экспортный текст — контуры, поэтому поиск/выделение текста в PDF не предоставляются. Mac-specific gestures и desktop behavior требуют проверки на реальном Mac.
