### Ограничения и воспроизведение предыдущего этапа

Старые толщины объектов и сохранённые defaults, включая 12, не нормализуются. Для нового системного стиля — 2; пользователь может явно выбрать «Системный стиль». Старые карточки mind map не переоформляются автоматически; имеющиеся достоверные связи сохраняются. Объекты без parent ID не превращаются в дерево по близости и не удаляются. Новые темы записываются в v3; чтение v1/v2 сохранено.

Автоматизация использует настоящие main/preload/renderer и файловые операции, но ответы нативных файловых диалогов подменены для воспроизводимых Save/Discard/Cancel. macOS, физический трекпад, системный DPI и перенос между мониторами не проверены. По последующему запросу собран и проверен распакованный Windows-пакет для локального запуска; установщик и проверка цифровой подписи не выполнялись. Полная межплатформенная приёмка не заявляется.

В заключительных повторных прогонах Windows clipboard стал недоступен: клавиша Copy доставлялась и `clipboard.writeText` вызывался, но немедленное чтение возвращало пустую строку. Минимальный Electron-пример без редактора воспроизвёл то же; Windows `Set-Clipboard`/`Get-Clipboard` сообщили `Requested Clipboard operation did not succeed`, в том числе вне ограниченной среды. Это не объявлено исправленным. Обычный desktop-тест сохраняет native-проверку и при такой среде падает. Явный `AXON_TEST_MEMORY_CLIPBOARD=1` подменяет только Electron clipboard для проверки остальных сценариев и IPC/копирования дерева; нативный round trip textarea в этом режиме помечается SKIP. Предыдущие успешные native-прогоны не заменяют повторение этого случая на рабочем пользовательском desktop.

Запуск: `npm run dev` либо `npm run build`, затем `npm start`. Для повторения UI-прогона сначала собрать приложение и выполнить `node tests/desktop.mjs` (создаёт общие fixtures), затем нужный desktop-скрипт из таблицы. Скрипты запускаются последовательно: они используют окна и системный clipboard. Для новых сценариев: `node tests/corrections-desktop.mjs`, затем `node tests/panels-desktop.mjs`.

Диагностический прогон остальных сценариев при недоступном clipboard (PowerShell): `$env:AXON_TEST_MEMORY_CLIPBOARD='1'; node tests/corrections-desktop.mjs`; после него удалить переменную командой `Remove-Item Env:AXON_TEST_MEMORY_CLIPBOARD` и повторить обычный native-прогон на рабочем desktop. Изолированный режим не считается проверкой OS clipboard.

Ручная проверка оставшихся платформенных случаев:

1. На Windows выставить системный масштаб 100/125/150%, перенести окно между мониторами с разным DPI. На macOS запустить текущую сборку; проверить Cmd вместо Ctrl и физический pan/pinch.
2. В окнах 1366×768 и 1920×1080 создать два блока и связь на 25/50/100/200%; проверить наконечник, выбор, move/resize и экспорт. Вернуться к исходному zoom: dirty не меняется.
3. Проверить инструменты и свойства у четырёх углов, шрифт и палитру во время русского многострочного ввода. На узком окне открыть меню масштаба и дополнительные инструменты; панели не должны пересекаться.
4. Создать mind map кликом, ветви слева/справа и два уровня. Добавить соседнюю тему, удлинить текст, перенести/скопировать/удалить поддерево, Undo/Redo, сохранить, открыть и экспортировать.
5. Открыть два одноимённых файла из разных папок и новый документ. Проверить tooltips, независимые view/историю, нативные Save As/Cancel/ошибку записи и отмену закрытия приложения без потери работы.

## Производительность

Контрольная сцена: 400 прямоугольников с русскими подписями, окно 1920×1080 CSS. Измеряется интервал `requestAnimationFrame` во время реальных синтетических pointer/wheel/keyboard событий Playwright, а не независимый GPU benchmark. Файлы: `performance.json` (pan), `performance-detail.json` (zoom/drag/select all). Эти измерения не являются гарантией FPS для другого оборудования или сцены с сотнями больших изображений.

Первый проход текста как контуров дал max zoom 330 мс. Экранный текст переведён на native SVG-text с теми же шрифтами и расчётом строк; экспорт сохраняет контуры. Итоговый прогон zoom/drag/selection выполнен без параллельной сборки:

| Операция            | Выборок | Медиана, мс | p95, мс | Максимум, мс |
| ------------------- | ------: | ----------: | ------: | -----------: |
| Pan                 |     189 |           5 |      15 |         20,1 |
| Zoom                |     211 |           5 |      30 |           45 |
| Drag                |     218 |           5 |    15,1 |         29,9 |
| Select All / Escape |      39 |         5,4 |    35,1 |        144,9 |

Только измерительные тесты отключают `backgroundThrottling`: автоматизация может перекрыть окно, и Chromium тогда намеренно ограничивает requestAnimationFrame примерно одним обновлением в секунду. Такой отдельный результат сохранён в `performance-background-throttled.json` и не используется как замер активного редактора. Настройка production не изменена. Это интервалы кадров при синтетических событиях, не обещание определённого FPS. Массовое выделение имеет реальные паузы; виртуализация и пространственный индекс не реализованы.

## Остаточные ограничения и непроверенное

- macOS DMG/ZIP собраны и базовый запуск проверен на обеих архитектурах. Полный набор сценариев редактора, остальные сочетания Cmd, физический pinch/трекпад и нативные macOS-меню требуют проверки на пользовательском Mac.
- Подпись Windows, Developer ID и notarization не выполнены. Установка/удаление NSIS и file association на чистой системе не проверены.
- Реальный multi-monitor DPI не проверен. 125% — тест renderer zoom-factor.
- История ограничена 100 завершёнными действиями; долговременная история не сохраняется. Recovery имеет задержку и гарантирует только завершённую запись.
- Текст экспорта — векторные контуры, без выделения/поиска текста в PDF. Стороннее редактирование импортированных схем не поддерживается.
- Маршруты не обходят фигуры автоматически; groups плоские. 10 000 объектов — защитный лимит формата, не обещание плавности.
- Renderer bundle около 1,07 МБ (до gzip): Vite выдаёт предупреждение размера chunk; сборка успешна, сеть при запуске не нужна.
- Native Computer Use не удалось подключить после повторов и сброса: Windows error 2, native pipe отсутствует. Проверка UI проведена через реальные снимки Electron, не по одному исходному коду.

Общий статус: рабочая Windows-версия с проверенными ключевыми сценариями и опубликованные macOS-сборки для arm64/x64 с проверенным запуском и базовым редактированием. Полная межплатформенная приёмка MVP не объявляется завершённой.
