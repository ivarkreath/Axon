## Сборки и запуск macOS

29.09.2026 успешно завершён [GitHub Actions run 36569366310](https://github.com/ivarkreath/Axon/actions/runs/36569366310), исходники `b08992bd2bcbbb684e605351500955931114b57a`. Сборка и проверки выполнены отдельно на нативных `macos-15` (arm64) и `macos-15-intel` (x64), macOS 15.7.9 (24G830), Electron 44.4.5, Node 24.

На каждой архитектуре прошли typecheck, lint и 24 теста Vitest. `tests/mac-packaged.mjs` проверил целостность DMG через `hdiutil verify`, распаковку ZIP, подпись всего bundle через `codesign --verify --deep --strict` и фактический запуск извлечённого `Axon.app`. Подтверждены `isPackaged: true`, context isolation, sandbox и отключённый Node integration. Созданы фигура и русский многострочный текст; Cmd+A внутри редактора не повредил документ, Cmd+S завершил ввод и записал корректный `.axon` на диск. Ошибок renderer не зарегистрировано. Путь диалога сохранения задан автоматически; ручная проверка самого нативного диалога не заявляется.

Снимки `mac-arm64-light.png` и `mac-x64-light.png` сняты после переключения на светлую тему и визуально осмотрены: кириллица читается, панели не перекрываются, фон документа сохраняется. JSON-отчёты и снимки доступны в Actions artifacts `macos-evidence-arm64` / `macos-evidence-x64` в течение 14 дней. Это ограниченный прогон упакованного приложения; весь Windows-набор desktop-сценариев на macOS не запускался.

Опубликован предварительный [релиз v0.1.0-macos](https://github.com/ivarkreath/Axon/releases/tag/v0.1.0-macos): DMG и ZIP для обеих архитектур, `SHA256SUMS.txt`. Подпись **ad-hoc** проверена фактически; Apple Developer ID и notarization отсутствуют. Прохождение Gatekeeper после скачивания на пользовательский Mac не проверено.

## Производительность

Контрольная сцена: 400 прямоугольников с русскими подписями, окно 1920×1080 CSS. Измеряется интервал `requestAnimationFrame` во время реальных синтетических pointer/wheel/keyboard событий Playwright, а не независимый GPU benchmark. Файлы: `performance.json` (pan), `performance-detail.json` (zoom/drag/select all). Эти измерения не являются гарантией FPS для другого оборудования или сцены с сотнями больших изображений.

Первый проход текста как контуров дал max zoom 330 мс. Экранный текст переведён на native SVG-text с теми же шрифтами и расчётом строк; экспорт сохраняет контуры. Итоговый прогон zoom/drag/selection выполнен без параллельной сборки:

| Операция            | Выборок | Медиана, мс | p95, мс | Максимум, мс |
| ------------------- | ------: | ----------: | ------: | -----------: |
| Pan                 |     189 |           5 |      15 |         20,1 |
| Zoom                |     211 |           5 |      30 |           45 |
| Drag                |     218 |           5 |    15,1 |         29,9 |
| Select All / Escape |      39 |         5,4 |    35,1 |        144,9 |

Только измерительные тесты отключают `backgroundThrottling`: автоматизация может перекрыть окно, и Chromium тогда намеренно ограничивает requestAnimationFrame примерно одним обновлением в секунду. Такой отдельный результат сохранён в `performance-background-throttled.json` и не используется как замер активного редактора. Настройка production не изменена. Это интервалы кадров при синтетических событиях, не обещание определённого FPS. Массовое выделение имеет реальные паузы; виртуализация и пространственный индекс не реализованы.

## Остаточные ограничения и непроверенное

- macOS DMG/ZIP собраны и базовый запуск проверен на обеих архитектурах. Полный набор сценариев редактора, остальные сочетания Cmd, физический pinch/трекпад и нативные macOS-меню требуют проверки на пользовательском Mac.
- Подпись Windows, Developer ID и notarization не выполнены. Установка/удаление NSIS и file association на чистой системе не проверены.
- Реальный multi-monitor DPI не проверен. 125% — тест renderer zoom-factor.
- История ограничена 100 завершёнными действиями; долговременная история не сохраняется. Recovery имеет задержку и гарантирует только завершённую запись.
- Текст экспорта — векторные контуры, без выделения/поиска текста в PDF. Стороннее редактирование импортированных схем не поддерживается.
- Маршруты не обходят фигуры автоматически; groups плоские. 10 000 объектов — защитный лимит формата, не обещание плавности.
- Renderer bundle около 1,07 МБ (до gzip): Vite выдаёт предупреждение размера chunk; сборка успешна, сеть при запуске не нужна.
- Native Computer Use не удалось подключить после повторов и сброса: Windows error 2, native pipe отсутствует. Проверка UI проведена через реальные снимки Electron, не по одному исходному коду.

Общий статус: рабочая Windows-версия с проверенными ключевыми сценариями и опубликованные macOS-сборки для arm64/x64 с проверенным запуском и базовым редактированием. Полная межплатформенная приёмка MVP не объявляется завершённой.
