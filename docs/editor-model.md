# Модель поведения редактора

## История и сеансы

`Editor.tabs` хранит по session ID отдельный `DocumentSession` (`src/editor/session.ts`): `EditorState`, `History` и состояние успешного сохранения. Активный `Editor.state` используется Canvas/Toolbar; переключение сохраняет ссылку на историю и состояние предыдущей вкладки. `acceptSession` обновляет метаданные и сохранённый снимок, не заменяя более новые renderer-правки. New/Open добавляют вкладку. `finishOperation` завершает текущий pointer-жест и фиксирует текст перед Save, переключением, закрытием и получением снимков. Камера, выделение и настройки не входят в Undo. Без view открытие при 100%, Fit только явный. documentName использует path/untitledName, а не title.

`DocumentContentState` (`src/model/content.ts`) удерживает immutable-снимок действительно сохранённого содержимого отдельно от ограниченной истории. `isDirty` читает готовое значение без сериализации. При изменении документа сравниваются ссылки объектов; поля сравниваются только у изменившихся объектов и assets. Индексы отличающихся объектов/ключей assets обновляются локально, метаданные проверяются отдельно. Undo к сохранённому содержимому и ручной возврат A → B → A делают вкладку чистой; новая ветка истории не получает чужую чистую точку. Успешный асинхронный Save A отмечает именно A, даже если текущий документ уже B. Обрезка истории не теряет baseline. Recovery — отдельная копия; она не меняет saved state.

`History` хранит до 100 immutable-снимков. Пустой commit игнорируется; новый commit очищает redo. Drag, resize, штрих, quick create и массовая команда дают одну запись. Preview не создаёт историю. Escape отменяет pointer-жест; при вводе текста завершает текстовый сеанс. Выбор свойства через formatChange — отдельная запись: незавершённый текст фиксируется, затем свойство, и сеанс продолжается с новым textBefore без размонтирования textarea/caret. UI открытие/фокус/ошибочный HEX не создают историю. Изменённый legacy-документ переходит в версию 3, открытие само по себе не мигрирует оформление.

No-op определяется сравнением сохраняемых полей с пропуском неизменных ссылок, без `JSON.stringify`; commit без изменений возвращает исходный снимок. Повтор установленного стиля и возвращённый в начальную точку жест не добавляют историю. Изменение текста/стиля проверяет schema только изменившихся объектов; изменение структуры или недоверенный ввод сохраняет полную проверку документа.

## Координаты и ввод

`screen = world × zoom + translation`. Zoom 10–400% сохраняет мировую точку под курсором. Pan: Space + drag, средняя кнопка, рука, обычное колесо. Ctrl/Cmd + колесо — zoom. Всё рассчитывается в CSS px, не device pixels. Поля и диалоги защищены от команд холста. Инструменты используют физические коды клавиш и работают при русской раскладке.

Нативный textarea поверх SVG поддерживает Enter, выделение, системную вставку и IME. Геометрия растёт под текст с метриками локальных Noto. Для ромба/эллипса/треугольника/БД/выноски задаётся безопасная область. Шрифт не сжимается при обычном resize. Текстовые параметры находятся в той же однострочной панели, редкое оформление — в «Ещё».

## Выделение и трансформация

Видимое выделение расширяется до плоской группы. Move/copy/delete/scale/export дополнительно включают потомков темы; смена свойства выбранного узла не применяется всему дереву. Move обрабатывает ID один раз, сохраняя блокировки. Copy добавляет внутренние связи; внешние концы становятся свободными. Новые ID получают объекты, группы и assets. Копия ветки получает свой корень и переназначенное родство. Экспорт берёт выбранный набор, не добавляя невыбранные обычные связи автоматически.

`resizeObject` изменяет одну фигуру, сохраняя шрифт; изображения всегда пропорциональны. `scaleSelection` преобразует весь выбранный фрагмент из `g.before` относительно противоположного угла. Общий коэффициент ограничивается размерами, шрифтом и толщиной штрихов; координаты и текст не округляются. Масштабируются позиции, размеры, шрифт, `style.padding`, локальные точки и толщина карандаша. Общие w/h карандаша не описывают его фактические границы и не ограничивают уменьшение. Толщины фигур/соединений сохраняются. Привязанные концы не трансформируются напрямую; свободные — только у выбранной связи. Внутренние подписи масштабируются вместе с фрагментом.

При блокировках множественный resize не выполняется частично. Панель предлагает исключить защищённые объекты; защищённая ветка исключается с её выбранными предками. Групповое оформление доступно только для свойств, общих всем выбранным типам; разные значения не подменяются значением первого элемента. Блокировки снимаются только явной командой.

На старте move/scale жеста готовятся расширенное выделение и исходные bounds; resize/move также удерживают кандидатов snapping. `src/model/indices.ts` хранит byId, порядок, группы, детей и зависимости связей в WeakMap по immutable-массиву объектов. При правке геометрии lookup получает актуальные объекты, а неизменная структура переиспользуется; изменение IDs, групп или привязок перестраивает её. Bounds неподвижных кандидатов кэшируются по объекту. Соединения, как и раньше, не участвуют в snapping; движущийся набор с потомками исключается целиком. Поиск кандидатов остаётся линейным, порог равен 6 CSS px / zoom. Завершение/Escape освобождает данные жеста; WeakMap не удерживает закрытые документы отдельно от живой истории.

## Связи и quick create

Четыре кардинальные точки вычисляются по силуэту; у треугольника боковые точки находятся на наклонных сторонах, у выноски bottom — на теле. `route` возвращает точки для bounds/длины, `connectorPath` — точный SVG-путь. Кривая — кубическая Безье с автоматическими касательными; её длина/середина приближённо рассчитываются по 64 сегментам. Сложного обхода препятствий нет. Подпись принадлежит связи и лежит на половине длины.

`nextObject` находит свободное место в соседней полосе; `quickCreate` создаёт пустую фигуру и связь одной транзакцией. `Editor.nodeConnection` используется для preview/click/drag бокового «+»: сохраняет цвет/маршрут/окончания defaults, но задаёт стандартную толщину 2 вместо сохранённой толщины инструмента. Уже существующие связи и preferences не изменяются. Маркеры вынесены на 18 CSS px; click/drag различается по 5 CSS px. Наведение создаёт только transient JSX-превью. Drag на узел создаёт связь, в пустоту — свободный конец. Escape возвращает исходный снимок. Инструмент соединения остаётся независимым.

У обычной связи концы перепривязываются с Alt для свободной координаты. У структурной `mindBranch` handles отсутствуют; прямое удаление только этой связи не повреждает дерево. Удаление узла удаляет инцидентные связи и откатывается одним Undo. Обычные связи не меняют родство.

`connectorMarkers` разрешает optional startMarker/endMarker поверх legacy arrows. `connectionHeads` использует касательные и ограничения длины; `model/markers.ts` даёт общую геометрию и bounds шести окончаний. Ствол заканчивается у основания замкнутого окончания; открытая стрелка не обрезает ствол. ObjectView использует полный путь для невидимого hit-path 12 CSS px. objectBounds включает штрих и окончания; contentBounds добавляет подпись и запас экспорта. Selection пропускает прямоугольники всех связей, сохраняя endpoints одиночной и общую рамку множественного выделения.

## Mind map

mindmap — инструмент создания; клик создаёт корень с вводом. createTopic задаёт текстовое представление v3 и отдельные defaults. addTopic пишет treeId/parentId/order/side, добавляет структурную ветвь 1,5 без наконечника. Сторона наследуется, корень имеет два плюса. Tab/Enter работают только на холсте.

layoutTopics после добавления и reflowChangedTopics после завершения текста раскладывают затронутую сторону одного дерева. Другие деревья/схемы не меняются; при вводе символа меняются только текст/размер темы. Изменение корня затрагивает обе стороны. Move/copy/delete сохраняют поддеревья, удаление и Undo атомарны. Legacy-карточки без presentation сохраняются, неизвестное родство не выводится из геометрии.

## Настройки и обратная связь

`Editor.style` меняет выделение либо defaults инструмента, но никогда оба одновременно. «Использовать стиль для новых» и сброс — явные команды. Новые фигуры нормализуют обводку до `SHAPE_STROKE_WIDTH`; legacy-значения не исправляются при чтении. Фон изменяется через историю активного документа; тема и defaults живут в preferences.

Панель 44 px показывает общие свойства/смешанные значения в одну строку; дополнительные контролы и команды — в PropertyPopover. visibleSelection скрывает полностью невидимое выделение; placeProperties использует видимую область, поля 14 px, резерв под dock и активный текст. Стиль создания центрирован над dock. Панель и всплывающие палитры ограничены viewport. Во время жеста объектная панель скрыта. Карандаш не создаёт selection ни во время, ни после штриха; его defaults доступны около toolbar.

## Привязки и отображение

Направляющие: 6 CSS px; точки связи: 18 CSS px; resize-handle: 9 CSS px; невидимый hit-path: 12 CSS px. Сетка имеет шаг 20 мировых единиц. Alt отключает snapping. Экранные примитивы соединений имеют минимум 0,85 CSS px. Системная толщина 2, наконечник 8×6 при 100%; экранный минимум длины 3 px ограничен 30% пути (по 22% для двух). Ствол укорочен под наконечник, кубическая форма сохраняется разбиением de Casteljau. Эти поправки не записываются в документ.

## Экспорт

Экран и экспорт разделяют каноническую геометрию и переносы текста. Только `ObjectView` передаёт viewport zoom для компенсации линий. SVG/PNG/PDF вызывают primitives без zoom; исключают preview, selection и controls. На экране SVG-text с локальными Noto; в экспорте контуры OpenType сохраняют кириллицу без внешних шрифтов. Bounds включают штрихи, наконечники и текст. Отступ 32 единицы, PDF — одна страница по содержимому. Асинхронный экспорт удерживает снимок документа и его название.
